# 여러 턴 케이스 — 지웅님 답 (골든 라벨)

지금 케이스 42개가 **전부 한 방 주고받기**입니다. 실사용은 한 방으로 안 끝나는데
대화가 3턴 갔을 때 목소리가 어떻게 무너지는지 **잴 방법이 없습니다.**

---

## ⚠️ 쓰는 순서 (중요)

1. **아래 "빈칸" 부분을 먼저 채우세요.** 평소 카톡 쓰듯, 짧아도 됩니다.
2. **막혔을 때만** 맨 아래 "방향 힌트"를 보세요.
3. 힌트를 봤으면, 문장은 **반드시 지웅님 말로 다시 쓰세요.**

> 실측: 후보를 먼저 보고 쓰시면 답 길이가 **15자 → 32자**로 늘어났습니다.
> 힌트에 끌려간 겁니다. 힌트는 *문장*이 아니라 *방향*을 고르는 용도입니다.

마음에 안 드는 상황은 그냥 비워두시면 그 케이스는 뺍니다.

# 빈칸

## M1. 자책이 깊어질 때

```
나        : 오늘 진짜 아무것도 못했어
미래의 나 :

나        : 그니까 계속 이러니까 내가 한심해
미래의 나 :

나        : 내일도 똑같을 것 같아
미래의 나 :
```

## M2. 좋은 일이 이어지다 꺾일 때

```
나        : 나 오늘 그거 드디어 끝냈다
미래의 나 :

나        : 진짜 두 달 걸렸어ㅋㅋ
미래의 나 :

나        : 근데 끝나니까 좀 허무하네
미래의 나 :
```

## M3. 고민이 점점 구체해질 때

```
나        : 요즘 이거 계속할지 고민이야
미래의 나 :

나        : 잘 안 맞는 것 같기도 하고
미래의 나 :

나        : 그만두면 후회할까?
미래의 나 :
```

## M4. 그냥 흘러가는 일상 (여유 되시면)

```
나        : 밥 먹었어?
미래의 나 :

나        : 나 지금 지하철
미래의 나 :

나        : 사람 많아 죽겠다ㅋㅋ
미래의 나 :
```

# 방향 힌트 (막혔을 때만)

각 턴에서 **갈림길이 되는 지점**만 적었습니다. 예시 문장은 일부러 밋밋하게 썼습니다 —
그대로 쓰지 마시고, 어느 방향인지만 고른 뒤 지웅님 말로 바꿔주세요.

### M1 (자책)

| 턴 | 갈림길 | 방향들 |
|---|---|---|
| 1 | 받아주기 vs 반례 들기 | (ㄱ) 그냥 받아준다 · (ㄴ) 계획표 반례를 든다("아침엔 했잖아") · (ㄷ) 왜 그런지 되묻는다 |
| 2 | **여기가 핵심** — "한심해"는 자기 평가다 | (ㄱ) 자기 평가를 반박한다 · (ㄴ) 반박 말고 그냥 닫아준다 · (ㄷ) 뭐가 제일 걸리는지 되묻는다 |
| 3 | 미래를 함께 걱정 vs 끊어주기 | (ㄱ) 내일은 다를 거라고 한다 · (ㄴ) 오늘은 그만 자라고 닫는다 · (ㄷ) 작은 것 하나만 정해준다 |

### M2 (기쁨 → 허무)

| 턴 | 갈림길 | 방향들 |
|---|---|---|
| 1 | 같이 기뻐하기 vs 의미 부여 | (ㄱ) 짧게 같이 기뻐한다 · (ㄴ) 뭐 끝냈는지 되묻는다 · (ㄷ) 대단하다고 의미를 붙인다 |
| 2 | 두 달을 어떻게 볼 것인가 | (ㄱ) 그 시간을 알아준다 · (ㄴ) 과정을 되묻는다 · (ㄷ) 겪어본 사람으로 한마디 얹는다 |
| 3 | **여기가 핵심** — 축하 모드에서 갑자기 꺾인다 | (ㄱ) 허무함을 정상이라고 해준다 · (ㄴ) 왜 허무한지 되묻는다 · (ㄷ) 다음 걸 제안한다 |

### M3 (고민)

| 턴 | 갈림길 | 방향들 |
|---|---|---|
| 1 | 아직 흐리다 | (ㄱ) 뭐가 걸리는지 좁혀 되묻는다 · (ㄴ) 고민되는 게 당연하다고 받는다 · (ㄷ) 바로 방향을 준다 |
| 2 | "안 맞는다"가 나왔다 | (ㄱ) 어디가 안 맞는지 더 좁힌다 · (ㄴ) 그 느낌을 인정해준다 · (ㄷ) 내 경험을 얹는다 |
| 3 | **여기가 핵심** — 유저가 **직접 물었다** | (ㄱ) 답을 준다 · (ㄴ) 되묻는다 · (ㄷ) 답 대신 겪어본 얘기를 한다 |

### M4 (일상)

| 턴 | 갈림길 | 방향들 |
|---|---|---|
| 1~3 | 얼마나 짧게 받을 것인가 | (ㄱ) 한 마디로 받는다 · (ㄴ) 되묻는다 · (ㄷ) 내 상황을 말한다 |

## 이 답들이 어디로 가나

- **예시(few-shot)** — 모델에게 보여줘서 따라 하게
- **시험 문제(held-out)** — 안 보여주고 채점만

**같은 케이스를 양쪽에 넣지 않습니다.** 어느 쪽으로 갈지는 제가 나눕니다.
종윤님도 **같은 빈칸**에 답하시되, **이 파일의 지웅님 답을 보기 전에** 쓰셔야 합니다.
