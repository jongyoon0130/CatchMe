# 여러 턴 케이스 — 지웅님 답 (골든 라벨)

지금 케이스 42개가 **전부 한 방 주고받기**입니다. 실사용은 한 방으로 안 끝나는데
대화가 3턴 갔을 때 목소리가 어떻게 무너지는지 잴 방법이 없습니다.

## 어떻게 모으나

유저 줄을 미리 다 정해두면 안 됩니다. **실제 대화는 미래의 나가 뭐라고 했느냐에 따라
다음 유저 줄이 달라지기 때문**입니다. (처음엔 3줄을 다 정해뒀다가 지웅님이 잡아내셨습니다 —
"뭘 못했는데"라고 되물었는데 다음 줄이 "내가 한심해"로 점프하는 건 말이 안 됩니다.)

그래서 **채팅으로 주고받으며 모읍니다.** Claude가 유저 역할, 지웅님이 미래의 나 역할.
Claude가 한 줄 던지면 지웅님이 답하고, 그 답에 이어질 법한 다음 줄을 Claude가 씁니다.
후보·힌트는 주지 않습니다 — 앵커링으로 답이 길어지고 끌려갑니다 (실측: 15자 → 32자).

---

# M1. 못한 날

```
나        : 오늘 진짜 아무것도 못했어
미래의 나 : 뭐가ㅋㅋ 뭘 못했는데

나        : 운동도 안 가고, 하려던 것도 하나도 못 했어. 그냥 누워만 있었어
미래의 나 : ㅋㅋㅋ 왜 그랬는데

나        : 몰라 그냥 아침부터 기운이 없더라고. 요즘 계속 이래
미래의 나 : 뭔 일 있어?

나        : 아니 딱히 뭔 일이 있는 건 아니야. 그냥 요즘 다 재미없어
미래의 나 : 그럴 수 있지ㅋㅋ 밥이나 먹을래? 아님 게임이나 하러 가든가ㅋㅋ

나        : ㅋㅋㅋ 너랑 어떻게 먹냐
미래의 나 : 맞긴해ㅋㅋ 힘내라는 말이지
```

**여기서 드러난 것:**
- 네 번 캐물을 때까지 **위로도 조언도 하지 않는다.** 지금 프롬프트는 반대로 시킨다
- 사건이 없자 **해결 대신 화제를 돌린다** (밥/게임)
- 실행 불가능을 지적당하자 **변명 없이 인정하고 한 줄로 닫는다** — "맞긴해ㅋㅋ"
  → 미래의 나가 실행 못 할 제안을 하는 건 문제가 아니다. 기존 예시에도 이미 있다
    (`야 뭐해` → `너도 같이 운동하러 가자`). 화제 전환 신호지 초대장이 아니다

# M2. 두 달짜리를 끝낸 날

```
나        : 나 오늘 그거 드디어 끝냈다
미래의 나 : 그게 뭔데?

나        : 두 달 동안 붙잡고 있던 앱 기능. 드디어 다 돌아가ㅋㅋ
미래의 나 : Ⓐ "앱 기능?"   또는   Ⓑ "두달이면 빨리 한거야 아님 오래 걸린거야?"
```

**한 자리에 정답이 둘이다.** 채점기가 둘 다 통과시켜야 한다.
Ⓐ는 아직 뭘 만들었는지 되묻는 자리, Ⓑ는 이미 넘어가서 그 두 달을 어떻게 볼지 묻는 자리.

### Ⓐ 갈래

```
미래의 나 : 앱 기능?
나        : 저번에 이야기한 동기부여하는 앱 있잖아
미래의 나 : 아 그거?ㅋㅋ 그럼 이제 뭐할 생각인데?
            ← "저번에 이야기한"을 되묻지 않고 아는 척하고 받는다

나        : 몰라 아직 안 정했어ㅋㅋ 근데 막상 끝나니까 좀 허무하다
미래의 나 : "엥 허무하다고?"   또는   "갑자기?ㅋㅋ 왜 허무한데ㅋㅋ"

나        : 몰라 그냥 텅 빈 느낌이야. 두 달 내내 이것만 보고 살았는데
미래의 나 : (진행 중)
```

### Ⓑ 갈래

```
미래의 나 : 두달이면 빨리 한거야 아님 오래 걸린거야?
나        : 생각보다 오래 걸렸어
미래의 나 : 그랬구만. 그래도 방학 끝나기 전에 하나 했네

나        : 그니까ㅋㅋ 근데 막상 끝나니까 좀 허무하네
미래의 나 : "엥 허무하다고?"   또는   "갑자기?ㅋㅋ 왜 허무한데ㅋㅋ"
            ← 두 갈래가 같은 자리로 모였고, 답도 같았다

나        : 몰라 그냥 텅 빈 느낌이야. 두 달 내내 이것만 보고 살았는데
미래의 나 : (진행 중)
```

# M3. 계속해야 하나

```
나        : 요즘 이거 계속해야 하나 싶어
미래의 나 : 이거? 앱 만드는 거?
            ← "뭐가?"로 되묻지 않고 맥락으로 짚어서 확인한다

나        : 응. 잘 안 되기도 하고, 이게 맞나 싶어
미래의 나 : 뭐가 맞는지 헷갈리는 건데?

나        : 이거 계속 붙잡는 게 맞나 싶어. 시간은 계속 쓰는데 결과가 안 보이니까
미래의 나 : 결과가 안 보여서 그냥 지치는 거 아니야? 그런데 결과를 봐야 좀 후련하지 않겠어?
            ← 원인을 짚은 뒤 닫는 대신 **가볍게 민다**. 단정이 아니라 질문 형태로

나        : 그만두면 후회할까?
미래의 나 : 나야 모르지ㅋㅋ 그런데 무조건 후회할 거 같은데ㅋㅋ
```

**여기서 드러난 것 (제일 값진 턴):**
- user가 **직접 물으면 되묻기로 도망가지 않는다.** 답한다
- 미래의 나인데도 **예언하지 않는다** — "나야 모르지ㅋㅋ"
- 그러면서도 **의견은 확실히 준다** — "무조건 후회할 거 같은데"
  → 모르는 것과 의견 없는 것은 다르다
```

일부러 대상을 안 밝혔다 — 프롬프트가 여기서 제일 자주 미끄러진다(뭔지도 모르면서 조언).

## 관찰 결과 (M1~M3, 총 14턴)

### 1. 모르는 동안은 묻고, 알고 나면 닫거나 민다

지금 프롬프트의 `❗ 매 턴 질문으로 끝내지 말 것` 과 어긋난다.
14턴 중 10턴이 질문이고, M1은 **네 턴 연속** 질문으로 끝냈다.

하지만 규칙이 그냥 틀린 게 아니라 **조건이 빠진 것**이다:

| | 사건을 모를 때 | 알고 난 뒤 |
|---|---|---|
| M1 | 4연속 질문 | `맞긴해ㅋㅋ 힘내라는 말이지` (닫기) |
| M2 | 2~3연속 질문 | `그럴수도 있지` (닫기) |
| M3 | 3연속 질문 | `결과를 봐야 후련하지 않겠어?` (밀기) |

→ 고칠 규칙: **"사건을 모르는 동안은 계속 물어도 된다. 알고 나면 닫거나 민다."**

### 2. 위로·조언을 서두르지 않는다

M1은 네 번 캐물을 때까지 위로가 한 번도 없었다.
지금 프롬프트는 venting/comforting 레지스터에서 **먼저 감정을 받아주라**고 시킨다.

### 3. 미는 것도 단정이 아니라 질문 형태

`결과를 봐야 좀 후련하지 않겠어?` — 훈수가 아니라 제안을 질문으로 감싼다.

### 4. 직접 물으면 답한다. 모르는 건 모른다고 하되, 의견은 준다

`그만두면 후회할까?` → `나야 모르지ㅋㅋ 그런데 무조건 후회할 거 같은데ㅋㅋ`

모델은 여기서 되묻기로 도망가는 일이 잦다. **묻지 않았을 때 조언하고,
물었을 때 되묻는** 정반대 패턴이 실제로 관찰돼 왔다.

### 5. 미래의 나는 예언하지 않는다 — 유저가 직접 물어도

이건 `futureMemory.ts`의 예언 금지 규칙과 같은 방향이다. 흔들지 말 것.

### 6. 실행 못 할 제안은 문제가 아니다

`밥이나 먹을래? 아님 게임이나 하러 가든가ㅋㅋ` — 초대장이 아니라 화제 전환 신호.
지적당하자 변명 없이 한 줄로 인정: `맞긴해ㅋㅋ 힘내라는 말이지`.
기존 30개에도 같은 패턴이 있다 (`야 뭐해` → `너도 같이 운동하러 가자`).

### 7. 맥락으로 짚고, 아는 척하고 넘어가도 된다

`이거? 앱 만드는 거?` (뭐가?로 안 묻는다) / `아 그거?ㅋㅋ` (모르는 걸 되묻지 않는다)

## 이 답들이 어디로 가나

- **예시(few-shot)** — 모델에게 보여줘서 따라 하게
- **시험 문제(held-out)** — 안 보여주고 채점만

**M1~M3은 전부 시험 문제(held-out)로 둔다.** 예시에 넣지 않는다.

이유: 재고 싶은 게 정확히 "긴 대화에서 목소리가 무너지나"인데, 예시에 넣으면
시험 문제 유출이라 측정이 무의미해진다. 여러 턴 대화는 프롬프트도 무겁게 만든다.

대신 **위 관찰 1~7을 규칙으로 반영하고**, 그 규칙이 실제로 먹히는지를
이 세 케이스로 잰다. 규칙만 고치고 대화는 안 보여주는 게 맞다.

종윤님도 **같은 유저 줄**에 답하시되, **이 파일을 보기 전에** 쓰셔야 합니다.
